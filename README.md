### About

I'm a Computer Engineer working in **data analytics for the fintech / investment sector** — SQL, Python, reporting and the measurement layer behind financial products.

For the **past ~1.5 years my focus has been AI**, and it has been hands-on rather than theoretical. I design and ship complete systems: LLM orchestration, data-extraction pipelines, generation pipelines, and the production web apps around them. I work end to end — architecture, implementation, tests, deployment.

I'm most interested in the point where **analytics meets AI engineering**: building systems that don't just answer a question once, but keep producing the answer reliably.

> Most of my current work lives in **private repositories** (product and client code), so the map below is the honest view of what I build. The public repos on this profile are from my university and bootcamp years and are kept as an archive.

### What I'm building

| Project | What it is | Stack |
| --- | --- | --- |
| **Scrapify** | Self-hosted web-scraping platform — actor catalog, request queue, datasets, cron scheduler, REST API and webhooks. Designed to degrade gracefully: the core runs on five dependencies, every heavier capability is optional. | Python · FastAPI · Playwright · Pydantic |
| **Agentic Super-Brain** | Vendor-agnostic multi-agent orchestration layer with local-LLM fallback, so a pipeline survives any single provider going down. | Python · LiteLLM |
| **Heavy Cloner** | Mirror crawler for heavy-design sites. Captures WebGL/three.js, WASM, Gaussian-splat and scroll-scrub assets through runtime network capture instead of static HTML parsing. Verified across 9 stacks with a golden-diff test harness. | Python · Playwright |
| **Heavy Generator** | The inverse of the crawler: a plain-language brief becomes a generated site with 3D/particle heroes, verified by runtime FPS and error checks. | Python · three.js · FastAPI |
| **AdForge** | Ad-creative pipeline that turns one product photo and a brief into UGC video variants, with a local/zero-cost engine by default and paid engines as an opt-in. | Node.js · Express · ffmpeg · TTS |
| **Dentora** | End-to-end clinic appointment system — booking form to record to admin panel, with no runtime dependencies. | TypeScript · HTML/CSS |
| **AI CRAFT** | AI-powered growth studio: client web builds, chatbots and outreach automation. | Next.js · TypeScript · Tailwind |
